#  My Favorite Series: Avatar: The Last Airbender

## About
**Avatar: The Last Airbender** is an animated fantasy series about *Aang*, the last Airbender, who must master all four elements and end the Fire Nation's war.

## Quick Facts
- **Genre:** Fantasy, Adventure, Animation
- **Seasons:** 3
- **Network:** Nickelodeon
- **Year started:** 2005

## The Four Nations
1. Water Tribe
2. Earth Kingdom
3. Fire Nation
4. Air Nomads

## Main Characters
| Character | Element | Role |
|-----------|---------|------|
| Aang | Air | The Avatar |
| Katara | Water | Waterbender |
| Sokka | None | Strategist |
| Toph | Earth | Earthbender |
